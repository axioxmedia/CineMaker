互动影游编辑器。推荐用 [GitHub 部署器](https://github.com/axioxmedia/github-deployer) 打开 `https://github.com/axioxmedia/CineMaker`，选 Release 里的 `CineMaker.exe`。

Windows 源码打包：`build_exe.bat` → `dist\\CineMaker.exe`。数据目录：`CineMakerData`。

插件仍对 **CineHost** 说话。停用后才出现红色卸载。资产后缀 `.aioassets`。
