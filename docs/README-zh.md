> 推荐用 **[GitHub 部署器](https://github.com/axioxmedia/github-deployer)** 拉取 Release 里的 EXE。

## 安装

部署器拉 EXE，或 `build\\build_exe.bat`，或 `python app.py`。

## 使用

左侧节点、中间 Blockly 积木画布、右侧检查器、底栏控制台。

## 插件

运行时导入 zip。对话 CineHost schema 3。见 `docs/PLUGIN.md`。

## 资产

导入封装为 `.aioassets`。

## 三维视口

GLB / glTF / FBX。棚灯可调。
